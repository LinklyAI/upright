# 坐直 Upright

**你坐直了吗？**

[English](README.md) | [简体中文](README.zh-CN.md)

运行在本地浏览器里的坐姿检测，无任何数据上传。打开网页、授权摄像头、校准 3 秒，之后离屏太近、低头、歪头、头前伸、驼背、歪坐或久坐时，页面渐变红并发出提示音。画面不离开本机，没有服务端。

## 运行

```bash
pnpm install
pnpm dev
```

用 Chrome 打开 Vite 给出的地址。摄像头权限要求 `localhost` 或 HTTPS。

1. 点「启动摄像头」，允许摄像头和通知权限。两个 MediaPipe 模型（约 9 MB）由站点自己托管，不依赖任何第三方主机，之后走浏览器缓存。
2. 端正坐好，点「校准」，保持 3 秒。校准结果存在 `localStorage`，下次打开自动沿用。
3. 之后可以切到别的标签页，或用「置顶小窗」把状态面板挂在屏幕角落。

语言、主题、灵敏度、声音开关和校准基线在刷新后都会保留。

## 工作原理

```
摄像头 → MediaPipe Face Landmarker + Pose Landmarker（WASM/WebGPU，本地）
      → metrics.ts   提取与尺度无关的指标
      → judge.ts     与校准基线比较 + EMA 平滑 + 迟滞阈值 + 持续时间
      → alerts.ts    页面变红 / 提示音 / 标签页标题 / 系统通知
```

| 问题     | 指标                                                                           | 默认进入 / 退出阈值      |
| -------- | ------------------------------------------------------------------------------ | ------------------------ |
| 离屏太近 | 瞳距像素 / 基线瞳距 − 1                                                        | 12% / 6%                 |
| 低头     | 面部变换矩阵解出的头部俯仰角（度）− 基线                                       | 12° / 6°                 |
| 歪头     | 两眼连线倾角（度）与基线之差的绝对值                                           | 12° / 6°                 |
| 头前伸   | (瞳距 / 肩宽) / 基线 − 1，身体不动只有头往前探时升高                           | 10% / 5%                 |
| 驼背塌陷 | 1 − (耳—肩中点高度 / 肩宽) / 基线；肩膀不可见时改用鼻子在画面中的下沉量 / 脸高 | 12% / 6%（鼻子备用 40%） |
| 耸肩     | 头不动、肩膀在画面中抬升的量，以肩宽为单位；头部任何移动都会被扣除             | 8% / 4%                  |
| 歪坐     | 肩线倾角偏差（14°）与鼻子偏离肩中点的横向距离（肩宽 30%）取较大者，需持续 8 秒 | 达到阈值 / 一半          |
| 提醒眨眼 | 距上次眨眼的秒数，来自闭眼系数；后台标签页看不到眨眼，会自动暂停               | 12 秒 / 6 秒             |
| 久坐     | 连续在画面中的时长，离开 2 分钟以上视为起身                                    | 45 分钟                  |
| 远眺     | 20-20-20 法则：距上次休息的看屏时长；离开画面 20 秒或提醒显示满 20 秒后重置    | 20 分钟                  |

- 所有判断都是**相对个人基线**的，因此摄像头俯仰角、偏移、身高、座椅高度都在校准时被抵消。
- 异常需持续 3 秒才报警，恢复 1.5 秒后自动解除；进入 / 退出阈值不同，避免临界抖动。
- **灵敏度**档位会整体缩放阈值和持续时间：低 ×1.4 / ×1.33，中 ×1，高 ×0.6 / ×0.67。久坐不受影响。
- 点击任意检测项可以关闭它；关闭后仍会测量，但不再报警。选择会被记住。提醒眨眼、久坐、远眺三项另有独立开关。
- 驼背改用耳朵而不是鼻子来量，低头不再被当成驼背。
- **暂停**会关闭摄像头并清除所有提醒，**继续**重新打开摄像头，不需要重新加载模型。
- 人脸离开画面视为「正常」，警报会自动清除。
- 阈值与时间常数都在 `src/config.ts`。

## 后台运行

Chrome 对正在采集摄像头的标签页不做内存回收和冻结，也豁免「每分钟一次」的强力节流，但仍会把定时器对齐到约 1 Hz。检测循环用 `setInterval` 而非 `requestAnimationFrame`（后者在隐藏标签页里完全停止），后台约 1 fps，对 3 秒判定窗口足够。播放提示音时标签页被视为「有声」，节流会进一步放宽。

如需更高的后台帧率，下一步是把 `MediaStreamTrack` 转移到 Web Worker，用 `MediaStreamTrackProcessor` 逐帧推理。

## 已知限制

- 头部俯仰的正方向依赖 MediaPipe 矩阵布局假设（列主序、z 朝向观察者）。如果低头时「头部俯仰」偏差为负，把 `src/config.ts` 里的 `HEAD_PITCH_SIGN` 改成 −1。
- 歪坐和头前伸只有肩膀可见时才工作。
- 没有接多模态大模型；本地指标处于临界区较久时抽一帧交给模型判断是一个可选的增强。
- 只针对 Chrome；Document Picture-in-Picture 是 Chrome 专有 API。
